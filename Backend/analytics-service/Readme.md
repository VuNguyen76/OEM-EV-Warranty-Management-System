# Analytics Service

Microservice thu thập và xử lý dữ liệu phân tích.

## Cấu trúc chính
- `src/controllers/`: Xử lý request từ API
- `src/services/`: Logic phân tích dữ liệu
- `src/routes/`: Định tuyến API
- `src/database/`: Kết nối cơ sở dữ liệu
- `index.js`: Điểm khởi động chính

## Chạy cục bộ
```bash
npm install
npm start
